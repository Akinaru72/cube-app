# 💛 Шаг 4. Собираем жёлтый крест

---

# 🌟 Почти у цели!

Посмотри на кубик.

Два слоя уже полностью собраны.

Осталась только верхняя сторона.

Начнём с первого шага —

соберём **жёлтый крест**.

---

# 🎯 Наша цель

Нужно сделать вот такую фигуру:

```
    🟨
🟨 🟨 🟨
    🟨
```

Не обращай внимания,

что уголки ещё могут быть неправильными.

Пока нас интересует только крест.

---

# 💡 Важный секрет

Сейчас мы смотрим **только на верхнюю сторону**.

Не переживай,

если боковые цвета временно перестанут совпадать.

Мы исправим это позже.

---

# 🟨 Что ты можешь увидеть

Перед началом верх кубика может выглядеть по-разному.

Например.

## Только центр

```
⬛ ⬛ ⬛
⬛ 🟨 ⬛
⬛ ⬛ ⬛
```

---

## Полоска

```
⬛ 🟨 ⬛
⬛ 🟨 ⬛
⬛ 🟨 ⬛
```

или

```
⬛ ⬛ ⬛
🟨 🟨 🟨
⬛ ⬛ ⬛
```

---

## Уголок

```
🟨 🟨 ⬛
🟨 🟨 ⬛
⬛ ⬛ ⬛
```

---

## Почти готовый крест

```
⬛ 🟨 ⬛
🟨 🟨 🟨
⬛ 🟨 ⬛
```

---

Все эти варианты —

совершенно нормальны.

---

# 🧠 Не пытайся придумать своё решение

На этом этапе уже начинают работать специальные последовательности движений.

Именно они постепенно превращают:

точку →

уголок →

полоску →

крест.

Поэтому просто выполняй движения,

не пытаясь угадать их результат.

Так быстрее и намного проще.

---

# ⚠ Если крест сразу не появился

Это тоже нормально.

Иногда один и тот же алгоритм нужно выполнить несколько раз.

Каждый раз верх будет становиться всё ближе к нужному виду.

---

# 🎉 Получилось!

Когда сверху появился жёлтый крест,

остановись.

Даже если боковые цвета пока не совпадают.

Так и должно быть.

Мы займёмся ими совсем скоро.

---

# ✅ Проверь себя

На верхней стороне есть крест?

⬜ Да

---

Все четыре жёлтых ребра смотрят вверх?

⬜ Да

---

Нижние два слоя остались полностью собранными?

⬜ Да

---

Если ответ **«Да»** —

ты снова всё сделал правильно!

🎉

---

# 🌈 Осталось совсем немного

Теперь нужно сделать так,

чтобы вся верхняя сторона стала жёлтой.

После этого кубик будет выглядеть почти собранным.

---

➡ Следующий шаг —

# 🌞 Собираем всю жёлтую сторону.
